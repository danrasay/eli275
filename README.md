# ELI 275 Entrepreneurial Finance course pages

Web pages for ELI 275 at Lewis & Clark College, published with GitHub Pages from the `main` branch.

Site: https://danrasay.github.io/eli275/

| Folder | Page |
| --- | --- |
| `w-walkthrough/` | [Organization W solution walkthrough](https://danrasay.github.io/eli275/w-walkthrough/) for Project 1. Password protected: the page is stored encrypted and opens in the browser with the password. Only the encrypted page is in this repository; its source and data are kept privately. |
| `yz-walkthrough/` | [Organizations Y and Z solution walkthrough](https://danrasay.github.io/eli275/yz-walkthrough/): a tour of the page at the folder's address, and the walkthrough itself at [`walkthrough/`](https://danrasay.github.io/eli275/yz-walkthrough/walkthrough/). See its README to rebuild and test. |

## Adding a page

Put each page in its own folder with an `index.html`, then add a link to it in the root `index.html` and a row to the table above. A push to `main` deploys the site.

Every page carries a `noindex` tag so search engines leave it out of results. `.nojekyll` tells Pages to serve the files as they are.
